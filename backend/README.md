# API Python

Backend FastAPI do Controle de Gastos, criado para concentrar as regras de
negócio e o acesso aos dados da aplicação.

A API será integrada ao front-end React e ao banco PostgreSQL do Supabase,
mantendo autenticação por usuário e separação dos registros financeiros.

Este módulo está em desenvolvimento e faz parte da evolução da aplicação,
que começou como um projeto local em Python e SQLite.
